# PulseForge

PulseForge is a browser-based music maker with a dark purple and blue studio interface.

## Features
- 16-step, two-octave piano roll using the C-major note set, with selectable C major, A minor, pentatonic and chromatic scales.
- Rhythm sequencer with kick, snare, hi-hat and clap.
- Chord arpeggiator with up, down, up/down and random patterns.
- Synth-generated loop library for keys, bass, beats, plucks, pads and retro sounds.
- Tempo and master-volume controls, browser project saving and WAV export.

## Run
Open `index.html` in a modern browser. Audio starts after you press Play or preview a sound, as required by browser audio policies.

PulseForge uses the Web Audio API and does not require external libraries or sample downloads.
